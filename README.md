# Feuille d'heures

Application web pour déclarer ses heures de travail à la semaine : horaires matin / soir / journée, congés, récup, formation, grève, calcul des heures sup, des heures de nuit et des primes, compteur de récupération et fiche Excel à envoyer au service paye.

Ouvrir : https://heikefr.github.io/feuille-heures/

Les données restent sur l'appareil (stockage du navigateur). Pense à faire une sauvegarde depuis Réglages.
